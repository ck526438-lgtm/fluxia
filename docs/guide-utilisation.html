1Ce que FormatPro3 Workflow fait vraiment

FormatPro3 Workflow est un éditeur de workflows par nœuds, dans l'esprit de n8n : vous posez des briques sur un canvas infini, vous les reliez, vous configurez chaque étape dans le panneau de droite, vous lancez l'exécution, et vous voyez les données circuler de nœud en nœud. Les arêtes s'illuminent, les nœuds affichent un anneau pendant le traitement puis une coche verte ou une secousse d'erreur, et le journal détaille les entrées, sorties et durées de chaque étape.

La règle « zéro démo »

Chaque nœud effectue une action réelle ou échoue honnêtement. Il n'existe aucun simulateur, aucune réponse inventée, aucun « mode démo » caché. Un nœud Envoyer un email appelle l'API Brevo et le mail part. Un nœud YouTube téléverse le MP4 sur Google. Sans identifiant, l'exécution s'arrête sur le nœud concerné avec l'explication exacte — y compris l'URL où créer la clé et les scopes requis.

Conséquence pratiqueUn message d'erreur dans FormatPro3 Workflow n'est jamais un mystère : il dit ce qui manque ou ce que la plateforme distante a refusé. Vous pouvez vous fier au journal pour diagnostiquer un vrai problème de production.

Automatisation métier sans serveur : veille et reporting, triage de leads, enrichissement de données, notifications d'équipe, publication multi-réseaux. Tout reste sur votre machine — aucun compte FormatPro3 Workflow, aucun cloud, aucune télémétrie.

2Installation et démarrage

Depuis le dépôt Git

git clone https://github.com/ck526438-lgtm/formatpro3-workflow.git
cd formatpro3-workflow
npm install

npm run dev      # développement — http://127.0.0.1:5173 (rechargement à chaud)
npm run build    # production — génère dist/
npm start        # relais local + sert dist/ sur http://127.0.0.1:5174

Node.js 18 ou plus récent est requis (npm run dev utilise Vite 8). npm start est optionnel : sans lui l'application tourne à 100 % dans le navigateur, à l'exception des appels bloqués par le CORS (voir chapitre 8).

Deux terminaux en développementEn mode npm run dev, Vite écoute sur 5173 et proxyfie automatiquement /api/* vers 5174. Lancez donc npm run dev dans un terminal et node server.mjs dans un second : l'application détecte seule la présence du relais (appel /api/health).

Ouvrir l'application

  • Local, développement : http://127.0.0.1:5173
  • Local, build de production : http://127.0.0.1:5174 après npm run build puis npm start
  • Sans installation : https://ck526438-lgtm.github.io/formatpro3-workflow/ — redéployée à chaque poussée sur main
La démo en ligne ne publie pas de vidéoLes nœuds Vidéo, Slack et Google Sheets exigent le relais local, qui n'existe pas sur GitHub Pages (site statique). Le message d'erreur l'indique explicitement et la solution est locale.

Charger un premier flux

Bouton Modèles dans la barre d'outils → choisissez un modèle → Charger. Le canvas se remplit avec un flux complet et paramétré. Sinon Ctrl K → « Importer un flux » pour charger un JSON exporté.

4Les concepts fondamentaux

4.1 Les éléments (items)

Une connexion ne transporte pas un objet : elle transporte une liste d'éléments (tableau de JSON). Chaque nœud reçoit cette liste et en produit une nouvelle. C'est ce qui permet à un Éclater de transformer une commande en dix éléments, ou à un Agréger de les recompter en un seul.

4.2 Les expressions {{ … }}

Partout dans les champs de paramétrage, une expression entre accolades est évaluée par élément, juste avant l'exécution du nœud. C'est du JavaScript strict.

VariableContenu
{{ $json.champ }}Le champ de l'élément en cours. {{ $json.a?.b ?? "—" }} fonctionne.
{{ $items.length }}Tableau complet des éléments reçus + index courant.
{{ $index }}Position de l'élément dans la liste (0, 1, 2…).
{{ $node["Mon nœud"].json.total }}Sortie d'un autre nœud, désigné par son libellé. Également .items, .all(), .first().
{{ $now.toISOString() }}Date du début de l'exécution (objet Date : toLocaleDateString("fr-FR"), getTime()…).
{{ $creds.maCle }}Valeur enregistrée dans le panneau Identifiants. Rien n'est ressaisi.
Chaque ou une expression entièreSi le champ contient uniquement {{ … }}, le résultat garde son type naturel (nombre, booléen, objet, tableau). Si l'expression est noyée dans du texte, elle est convertie en chaîne — et un objet est sérialisé en JSON.

4.3 Ports et branchements

Un nœud peut avoir plusieurs sorties numérotées : Condition a Vrai / Faux, Aiguillage a jusqu'à trois cas. Une branche non empruntée ne s'exécute pas : ses nœuds apparaissent comme ignorés au journal, et le flux continue sans erreur.

4.4 Exécuter le flux, exécuter jusqu'ici

  • Exécuter (Ctrl ↵) : parcours en ordre topologique complet.
  • Exécuter jusqu'ici (clic droit sur un nœud) : n'exécute que tous les ancêtres du nœud, puis s'arrête sur lui. Idéal pour tester une étape coûteuse sans déclencher les suivants — ni envoyer dix emails.
  • Arrêter : interrompt l'exécution en cours.
  • Vitesse : Normal laisse voir les animations, Turbo exécute sans temporisation.

4.5 Sauvegarde, historique, partage

  • Sauvegarde automatique dans le localStorage du navigateur (indicateur « Enregistré ») ; Ctrl S force l'écriture.
  • Annuler / rétablir : Ctrl Z / Ctrl ⇧ Z, sur la structure du graphe.
  • Export JSON : le flux complet (nœuds, liens, positions, paramètres) dans un fichier. Import pour le rejouer ailleurs ou le versionner dans Git.
  • Copier / coller / dupliquer : Ctrl C / Ctrl V / Ctrl D.
Le localStorage n'est pas une sauvegardeIl est propre à un navigateur et à un profil. Exportez en JSON avant de changer de machine, de nettoyer les données de navigation, ou avant une modification risquée.

7Publier une vidéo sur 7 réseaux

Les deux règles communes

  1. Le relais local doit tourner (npm start). Il récupère les octets de la vidéo et les transmet à la plateforme — sans lui, le nœud s'arrête avec ce message, avant même de vérifier les clés.
  2. URL directe vers le fichier : un lien qui renvoie le MP4, pas une page de lecture. Si l'URL renvoie du HTML ou du texte, le relais refuse avec « L'URL ne renvoie pas une vidéo… ».

Le contrôle préalable (preflight)

Avant le moindre octet téléchargé, chaque nœud vidéo vérifie que toutes ses informations d'identification sont remplies et échoue immédiatement avec la phrase exacte — où créer la clé et quels scopes cocher. Résultat mesuré : une exécution mal configurée échoue en ~23 ms au lieu de ~1 s, sans téléverser une vidéo de 100 Mo pour rien. Vous ne payerez jamais un téléchargement pour découvrir ensuite un jeton manquant.

Deux familles de fonctionnement

ModeRéseauxDétail
URL remise à la plateformeInstagram, Facebook, TikTokFormatPro3 Workflow transmet l'URL ; ce sont les serveurs du réseau qui viennent chercher le fichier. L'URL doit donc être en HTTPS, publique, sans redirection ni protection par cookie. Instagram affiche même un conteneur créé avec succès avant d'échouer au polling : FormatPro3 Workflow attend et signale l'échec réel.
Octets envoyés par FormatPro3 WorkflowYouTube, Mastodon, Bluesky, XLe relais lit la vidéo et la découpe selon le protocole du réseau (multipart YouTube, tranches de 5 Mo pour X, blob brut pour Bluesky). Taille totale plafonnée à 200 Mo côté relais.

Ce que chaque réseau impose

RéseauContraintes réelles (vérifiées sur l'API officielle)
YouTubeUn quota d'environ 100 téléversements par jour ; compte Google normal obligatoire (les comptes de service ne peuvent pas téléverser) ; le jeton se passe en en-tête Authorization: Bearer.
MastodonFormats MP4 / MOV / WebM ; la limite de poids dépend de votre instance (FormatPro3 Workflow lit video_size_limit via /api/v2/instance et la respecte) ; un seul média vidéo par post ; environ 30 téléversements par 30 minutes.
BlueskyMP4 uniquement — un autre format est rejeté à la publication et FormatPro3 Workflow vous dit de réencoder en H.264/AAC. Limite d'envoi fixée par le PDS : ~5 Mo sur un serveur auto-hébergé par défaut, davantage sur les hébergeurs officiels. Voie simple retenue : le fichier est stocké tel quel, sans transcodage par le service vidéo de Bluesky — la publication est réelle, mais moins optimisée que depuis l'application mobile.
XTranches de 5 Mo, puis transcodage asynchrone : FormatPro3 Workflow attend l'état succeeded avant de publier, et signale un failed (format ou durée non supportés).
InstagramCompte professionnel lié à une Page, app Meta approuvée, minimum 15 minutes entre deux Reels (code 382), HTTPS sans redirection.
FacebookJeton de Page (pas personnel), permission publish_video ; l'URL est passée en file_url.
TikTokApp non auditée : SELF_ONLY obligatoire et maximum ~5 publications par utilisateur sur 24 h ; en mode URL, votre domaine doit être vérifié dans le portail développeur, sinon video_pull_failed.
Tester sans publier sur votre vrai compteYouTube Privée, Mastodon Abonnés, Bluesky avec un compte de test, TikTok Moi uniquement : le téléversement est réel, l'audience non. C'est la bonne façon de valider un flux avant de l'exposer.

8Le relais local en détail

server.mjs — zéro dépendance, écoute uniquement sur 127.0.0.1:5174. Il ne stocke rien sur disque et ne parle qu'aux API que votre flux appelle.

RouteRôle
/api/healthSignale la présence et la version du relais ; l'app l'appelle une seule fois et adapte l'interface.
/api/relayTransfert HTTP générique (méthode, en-têtes, corps) vers une API qui refuse le navigateur.
/api/sheets-appendSignature du JWT de compte de service et appel à l'API Google Sheets.
/api/video/fetchTélécharge la vidéo depuis son URL et la retient en mémoire (clé temporaire).
/api/video/multipart · /chunk · /relatedEnvoie des tranches du fichier selon le protocole de la plateforme (segments, plages, corps structuré).
/api/video/releaseLibère la vidéo dès que la publication est terminée.

Limites et sécurité

  • 200 Mo maximum par fichier vidéo, 15 minutes de rétention en mémoire (purge automatique), délai de téléchargement 180 s, d'envoi 300 s.
  • Une réponse HTML ou texte à une URL de vidéo est refusée explicitement : cela rattrape les liens de lecture au lieu des liens de fichier.
  • Aucune donnée ne sort de votre machine sans votre flux ; l'écoute sur 127.0.0.1 rend le relais inatteignable depuis le réseau.
  • Si un appel répond « Route inconnue », c'est qu'un relais d'une version antérieure tourne encore : relancez npm start.
Fonctionnement hors ligneSans relais, tout le reste de l'application continue de fonctionner — y compris les IA locales, le CSV, les conditions et Code JS. Le relais n'est qu'un pont réseau, jamais une dépendance de l'éditeur.

12Vos données, sécurité et bonnes pratiques

  • 100 % local. Flux et identifiants vivent dans le localStorage du navigateur. Aucun serveur FormatPro3 Workflow, aucun compte, aucune télémétrie.
  • Le relais ne fait que transiter, en mémoire, sur 127.0.0.1. Les jetons ne sont jamais écrits sur disque par le relais.
  • Les IA locales n'envoient rien ; seuls les moteurs « OpenAI compatible » sortent votre texte, et seulement si vous fournissez une clé.
  • Ne partagez jamais un export JSON contenant des secrets : les paramètres des nœuds sont dedans. Préférez {{ $creds.* }} et gardez les clés hors du fichier, ou nettoyez-les avant publication.
  • Méfiez-vous du nœud Code JS : JavaScript exécuté sans bac à sable. Relisez tout flux importé contenant ce nœud.
  • Rotation : les jetons d'application (Meta, X, TikTok) expirent ou sont révoqués ; en cas de refus d'authentification, régénérez avant de chercher un bug dans le flux.
  • Quotas : YouTube ~100 uploads/jour, TikTok ~5 publications/24 h par utilisateur non audité, Mastodon ~30 uploads/30 min, Instagram 15 min entre Reels. Pour un flux récurrent, ajoutez Attendre et limitez avec Limiter.
  • Accessibilité : renseignez le Texte alternatif vidéo sur Mastodon et Bluesky — c'est un champ réel, pas un décor.

Ajouter un nœud

  1. Une entrée dans src/data/catalog.tsx : type, libellé, famille, icône, description, nombre d'entrées, libellés de sorties, liste des paramètres.
  2. Un case dans l'exécuteur de nœud (src/engine/engine.ts) — ou une fonction dédiée si le nœud appelle un réseau, comme dans video.ts.
  3. Formulaire, poignées, palette, menu contextuel, export JSON : tout suit automatiquement.
